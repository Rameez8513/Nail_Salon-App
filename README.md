## Project Overview

Nail Salon is a staff management app for beauty and nail salons, built with Flutter and Firebase. Employees manage their daily schedule, clients, and services, while admins oversee staff, appointments, and inventory.

- **Platform:** Android & iOS
- **Framework:** Flutter
- **Backend:** Firebase (Auth, Cloud Firestore)
